# 🎭 Mafia Bot 1.9

Телеграм-бот для игры в мафию в групповых чатах: 9 ролей, ночные
действия в ЛС, голосование, рейтинг с сезонами, ачивки, магазин и
полноценная админ-панель. aiogram 3 + SQLAlchemy 2 (SQLite / PostgreSQL),
три языка интерфейса (ru / en / uz).

---

## ✨ Что умеет

- **Игра** — лобби с таймером, ночь → день → номинация → голосование →
  последнее слово, напоминания о времени, автопропуск АФК.
- **9 ролей** — Житель, Мафия, Дон, Адвокат, Детектив, Сержант, Доктор,
  Путана, Маньяк. Опциональные роли включаются в меню «⚙️ Настройки».
- **Ночь в ЛС** — выбор целей кнопками, общий чат мафии, чат мёртвых,
  мут живых и мёртвых в группе ночью.
- **Прогресс** — MMR-рейтинг с ежемесячными сезонами и наградой топ-10,
  35 ачивок с выплатой монет, профиль `/me`, пять таблиц лидеров.
- **Экономика** — монеты за игры, магазин из 20 товаров с вкладками и пагинацией (косметика +
  карты ролей), инвентарь, промокоды.
- **Карты ролей** — покупаются или выдаются админом/промокодом, активируются
  в `/inventory` и дают заявку на роль в следующей игре (при конфликте
  карта возвращается).
- **Админка** — `/admin` (кнопки в ЛС) и 44 текстовые команды, журнал
  действий на 50 записей с пагинацией, тех-работы, фича-флаги.
- **Меню команд** — подсказки по `/` отдельно для групп, ЛС и админов.

## 🚀 Запуск

```bash
git clone <repo> && cd Mafia-bot
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впиши BOT_TOKEN и ADMIN_IDS
python run.py
```

В группе боту нужны права админа (удаление сообщений и мут) и отключённый
privacy mode (`/setprivacy` → Disable у @BotFather).

## 📋 Команды

**Игра:** `/newgame` (`/game`, `/mafia`), `/join`, `/leave`, `/startgame`,
`/settings`, `/extend`, `/shorten`, `/cancel`, `/alive`, `/role`.

**Ночью в ЛС (если нет кнопок):** `/kill`, `/check`, `/heal`, `/block`,
`/search`, `/defend`, `/maniac`.

**Профиль и экономика:** `/me` (`/profile`), `/stats`, `/top`, `/shop`,
`/balance`, `/inventory` (`/inv`), `/promo`, `/lang`, `/help`.

**Админу:** `/admin` — панель с кнопками, `/adminhelp` — полный список.
Коротко: модерация (`/ban`, `/unban`, `/banlist`, `/warn`, `/mute`, `/banchat`),
игры (`/games`, `/forceend`, `/skipphase`, `/kickplayer`, `/revealroles`),
экономика (`/givecoins`, `/takecoins`, `/giveitem`, `/giverole`, `/takerole`,
`/invof`, `/multiplier`, `/promonew`, `/promolist`, `/promodel`),
система (`/astats`, `/audit`, `/flags`, `/maintenance`, `/broadcast`,
`/reloadlocales`, `/health`, `/addadmin`, `/deladmin`, `/admins`).
Цель можно указать id, `@username` или ответом на сообщение; длинные
списки постранично: `/banlist 2`, `/promolist 3`, `/games 2`.

## ⚙️ Настройка

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_IDS` | id владельцев через запятую |
| `DATABASE_URL` | БД; по умолчанию `sqlite+aiosqlite:///mafia.db` |
| `DATA_DIR` | каталог для SQLite-файла (на Render — `/var/data`) |
| `PORT` | порт health-сервера |
| `LOG_LEVEL` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |

Тайминги и набор ролей настраиваются прямо в лобби через `/settings`,
глобальные фича-флаги (магазин, карты ролей, чат мёртвых, выстрел
комиссара) — в `/admin` → Система.

## ☁️ Деплой на Render

`render.yaml` уже в репозитории: Render → New → Blueprint → выбрать репо,
задать `BOT_TOKEN` и `ADMIN_IDS`.

База данных **не пересоздаётся при деплое**:

- в `render.yaml` подключён диск `mafia-data` на `/var/data`, `DATA_DIR=/var/data`;
- относительные SQLite-пути автоматически привязываются к `DATA_DIR`;
- альтернатива — PostgreSQL: `DATABASE_URL` подставляется Render'ом,
  `postgres://` конвертируется в `postgresql+asyncpg://` автоматически;
- новые колонки добавляются мягкой миграцией при старте.

## 🏗️ Архитектура

```
app/
  main.py            точка входа, DI, меню команд
  config.py          настройки (pydantic-settings)
  handlers/          lobby, day, night, basic, shop, admin, admin_panel
  services/          orchestrator, lobby, day, night, timer, progress, admin
  game/              роли, баланс, ачивки, магазин, константы
  db/                модели и репозитории (вкл. progress, inventory)
  i18n/, locales/    три языка, 642 ключа в каждом
  keyboards/         inline-клавиатуры и callback-роутинг
tests/               178 тестов
```

Игровое состояние живёт в памяти (`GameSession`), в БД попадают итоги,
статистика, экономика и админ-журнал.

## 🛠️ Разработка

```bash
pytest -q                 # 178 тестов
python -m compileall app  # быстрая проверка синтаксиса
```

При добавлении текстов обновляй все три файла в `app/locales/` — тесты
проверяют, что наборы ключей совпадают.
